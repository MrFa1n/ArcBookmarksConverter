# Arc to Chrome Bookmarks

Экспорт боковой панели [браузера Arc](https://arc.net/) (пространства, папки,
закреплённые и обычные вкладки) в стандартный файл закладок формата Netscape
HTML, который умеет импортировать любой браузер — Chrome, Firefox, Safari,
Edge, Brave и т. д.

Arc хранит состояние боковой панели в файле `StorableSidebar.json` с довольно
непростой внутренней структурой (чередующиеся пары ключ/значение, виртуальные
контейнеры для закреплённых вкладок, связи родитель/потомок по ID). Этот
инструмент разбирает эту структуру и формирует чистый файл закладок с
сохранением папок.

*(Read in English: [README.md](README.md))*

## Зачем

Arc закрывается / вы переходите на другой браузер, и не хочется терять годами
собранные вкладки и папки. Браузеры не умеют напрямую обмениваться данными
друг с другом, но все понимают формат закладок Netscape HTML — он и служит
мостом.

## Веб-версия

**[Открыть конвертер](https://MrFa1n.github.io/ArcToHtml/)** — перетащите
свой `StorableSidebar.json`, получите `arc_bookmarks.html` обратно. Ничего
устанавливать не нужно, файл никуда не загружается: это статическая
страница, вся обработка идёт прямо в браузере на чистом JavaScript (см.
[`docs/arc-converter.js`](docs/arc-converter.js) — это прямой порт Python-
скрипта ниже, результат побайтово совпадает).

## Использование (командная строка)

Нужен Python 3.10+, никаких сторонних зависимостей.

1. Найдите файл `StorableSidebar.json`. На macOS он обычно лежит здесь:
   ```
   ~/Library/Application Support/Arc/StorableSidebar.json
   ```
2. Запустите экспорт:
   ```bash
   python3 arc_to_chrome.py "/путь/к/StorableSidebar.json" -o arc_bookmarks.html
   ```
   Либо, если положить `StorableSidebar.json` рядом со скриптом, просто:
   ```bash
   python3 arc_to_chrome.py
   ```
3. Импортируйте `arc_bookmarks.html` в новый браузер:
   - **Chrome**: `chrome://bookmarks` → меню ⋮ → *Импортировать закладки*
   - **Firefox**: Закладки → Управление закладками → Импорт и резервные копии → Импортировать закладки (HTML)
   - **Safari**: Файл → Импортировать из → Файл закладок HTML

### Что экспортируется

- **Одна папка верхнего уровня на каждый Space из Arc**, с его названием.
  Поскольку Chrome (и большинство браузеров) при импорте кладёт всё в одну
  общую папку «Импортировано», внутри неё будет ровно столько подпапок,
  сколько у вас Spaces в Arc, а не одна большая плоская куча.
- Внутри папки каждого Space вложенность и порядок папок сохраняются ровно
  такими же, как в `StorableSidebar.json`, а все корневые контейнеры этого
  Space (их у Arc часто несколько) разворачиваются прямо туда — без
  дополнительной вложенной папки-обёртки.
- **Строка «Top Apps» из Arc** (мелкие вкладки-иконки, которые показываются
  одинаково под каждым Space — они общие, а не принадлежат какому-то одному
  Space) попадают в свою отдельную папку верхнего уровня «Arc — Shared
  Pinned».
- Всё, что так и не удалось привязать ни к одному Space или папке, попадает
  в последнюю запасную папку «Arc — отдельные вкладки», чтобы ничего не
  терялось молча.
- Дубликаты (по ID, либо по совпадению title+URL) пропускаются.

`StorableSidebar.json` у Arc не всегда называет вещи так, как можно было бы
ожидать по интерфейсу (например, список контейнеров Space вперемешку
содержит служебные слова вроде `"pinned"`/`"unpinned"` и реальные ID
контейнеров, причём не всегда последовательно). Чтобы не зависеть от этого,
экспортёр определяет тип каждого корневого контейнера по его собственному
полю (`data.itemContainer.containerType`), а не по этим словам-маркерам.

## Санитизация файла перед тем, как им поделиться

Если вы хотите приложить свой `StorableSidebar.json` к баг-репорту или
предложить новый тестовый файл — **не делитесь им в чистом виде**: в нём
настоящая история вкладок, их заголовки и внутренние идентификаторы.
Используйте утилиту для редактирования:

```bash
python3 tools/sanitize_arc.py StorableSidebar.json -o StorableSidebar.sanitized.json
```

Она заменяет URL, заголовки и всё похожее на email, ID, токен и прочие
чувствительные значения на предсказуемые заглушки, сохраняя структуру JSON
(так что файл остаётся полезным как тестовый фикстур). **Перед тем как
делиться результатом, обязательно проверьте его вручную** — это
эвристический фильтр, а не гарантия.

## Структура проекта

```
arc_to_chrome.py        # экспортёр — StorableSidebar.json -> HTML с закладками
tools/sanitize_arc.py   # редактирует файл перед тем, как им поделиться
docs/                    # веб-версия для GitHub Pages (та же логика, порт на JS)
examples/                # санитизированный пример StorableSidebar.json для тестов
tests/                   # тесты (стандартный unittest, без зависимостей)
```

## Запуск тестов

```bash
python3 -m unittest discover -s tests -v
```
