Arc to Chrome Bookmarks

Turn Arc's StorableSidebar.json into a bookmarks file any browser can import — one folder per Space, nesting and order preserved.

Everything happens locally in your browser. Your file is never uploaded anywhere — this page has no server and makes no network requests with your data. (source on GitHub, verify for yourself.)
Drop StorableSidebar.json here or click to choose a file
On macOS it's usually at ~/Library/Application Support/Arc/StorableSidebar.json
How to import the result into Chrome
  1. Open chrome://bookmarks
  2. Click the ⋮ menu in the top right
  3. Choose Import bookmarks and pick the downloaded file
  4. Your Spaces show up as folders under "Imported"
